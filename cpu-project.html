5 Stage Pipelined ARM CPU

Designed and implemented a fully functional 64-bit ARM LEGv8 processor—first as a single-cycle CPU and later as a 5-stage pipelined architecture in VHDL. Through this project I moved from seeing computers as magical machines to understanding and recreating their inner logic, building everything from instruction decoding and ALU control to handling data hazards, branching, and multi-stage signal propagation, all while strenghtening my VHDL skills.

The diagram shows these stages connected in a pipeline, with pipeline registers (IF/ID, ID/EX, EX/MEM, MEM/WB) between them. These registers hold all necessary values (operands, control signals, immediates, addresses) so each stage can operate independently on a different instruction each clock cycle, allowing for a higher instruction throughput.

I verified the CPU by writing countless testbenches, using GHDL to simulate the VHDL design and GTKWave to inspect internal signals individually. This let me trace each instruction as it moved through the pipeline, confirm register writes and memory accesses, and observe real data/control hazards—providing full visibility into the processor’s behavior

I learned that all of the individual components of the CPU are relatively simple, but when combined together they can become very powerful.
