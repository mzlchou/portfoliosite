Page Rectification Pipeline

This project implements an automatic document rectification pipeline that detects a document within an image, finds its corners, and applies a homography transform to produce a top down, flattened version of the page. The pipeline processes all images in an input folder and outputs rectified versions to an outputs directory

This is an example of how it works.

The pipeline detects a document within an image, identifies its four corners, and applies a homography transform to produce a clean, top-down view of the page. The pipeline performs grayscale conversion, Gaussian blurring, Canny edge detection, morphological processing, and contour extraction to isolate the document. It then approximates the largest contour using Ramer–Douglas–Peucker polygonal simplification and selects or recovers four corner points, ordering them consistently before computing a homography with OpenCV.

These were all mathematical concepts that I learned in my computer vision class, so it really helped a lot to implement them in a real project to understand them even better.
