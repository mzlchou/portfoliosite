Hand Signal Instrument

My group built an interactive audio-synthesis system on an STM32L432KC microcontroller that plays musical notes based on ASL hand-sign number recognition. A custom CNN model running on my laptop classifies the hand gesture, sends the predicted number to the microcontroller over UART, and the STM32 converts that value into a musical note by adjusting a PWM-generated audio signal. The system uses TIM2 for high-frequency PWM output, SysTick for precise timing, and the ADC for reading joystick input, which we used to control when the sound should play.

I trained the classification model and implemented the UART communication pipeline that streams real-time inference results to the STM32.

We tried implementing a camera interface and the classification model on the STM32 itself but we couldn't get it in time for our final project presentation.

This was our project poster. Group members: Jonah Pflaster, Michael Chou, and Elliot Friesen. (The top left photo of all of us is actually the downsized images that the computer uses for classification!)

This system gave me experience with low-level peripheral configuration, real-time signal processing, and direct register-level programming on the STM32 platform with the CMSIS framework.
