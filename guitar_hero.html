Guitar Hero on FPGA

My group developed a real-time Guitar Hero based game on an FPGA using VHDL, integrating VGA graphics, audio synthesis, and a custom guitar-controller input system. I designed the full game logic and hardware VGA renderer that draws falling blocks/notes based on screen position and a key comparison unit that checks the player’s inputs against expected notes each frame. These are then compared for your ending score, that converts note accuracy into BCD values.

Group members (in order): Cooper Bailey, Michael Chou, Paul Wang, and Max Harrington.

We implemented real time audio synthesis in VHDL by generating square wave tones in the FPGA. Each of the toy guitar's 5 buttons are mapped to a different frequency by adjusting the wave period, and a counter based oscillator produced the audio signal. It essentially works as an instrument on it's own! The result is a fully hardware-driven game loop that runs smoothly on the FPGA with no CPU or software involved.

This was the final project for Tufts ES4, digital logic and circuits, which I am a teaching assistant for. I am guiding a group now through their own implementation of Guitar Hero in SystemVerilog.
